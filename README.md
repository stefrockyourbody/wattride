# WattRide

Eine kleine Browser-App für den Rollentrainer (z. B. Decathlon D100): Watt einstellen (ERG), eigene Trainings anlegen und starten, Puls anzeigen, mit einer Fahransicht wie bei Zwift.

**App öffnen:** https://stefrockyourbody.github.io/wattride/

Funktioniert in Google Chrome oder Microsoft Edge (Laptop, Android). Auf iPhone/iPad die kostenlose App „Bluefy“ als Browser verwenden.
